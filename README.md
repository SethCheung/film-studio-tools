# Film Studio Tools

影视制作公司内部工具套件。

## 产品

- **Timeline Manager** — 项目时间线管理（月历/时间线/甘特图）
- **Quote Generator** — 报价单生成系统（开发中）
- **Feishu Integration** — 飞书连动（规划中）
- **AI Assistant** — 本地大模型辅助（规划中）

## 快速开始

### 环境要求
- Node.js 20+
- M3 Ultra Mac 或同等性能机器

### 安装

```bash
npm install
```

### 启动

```bash
npm start
```

访问 http://localhost:3000

### 部署

详见 [docs/DEPLOY.md](docs/DEPLOY.md)

## 技术栈

- **后端**：Express.js + SQLite
- **前端**：原生 HTML/CSS/JS + PWA
- **部署**：Cloudflare Tunnel
